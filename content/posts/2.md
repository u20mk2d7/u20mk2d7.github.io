High-Frequency Trading (HFT) is often described as a problem of building trading strategies that operate at very high speed. In practice, however, a competitive HFT system is much more than a fast strategy.


- Set up SSH
- Debugging: lldb(gdb) run, break, next, step, continue, print, bt, info threads, thread, watch, AddressSanitizer (ASan), UndefinedBehaviorSanitizer (UBSan), ThreadSanitizer (TSan)
Valgrind: memory debugging

ASan: memory safety

UBSan: undefined behavior

TSan: data races


- Performance tooling: perf, top, htop, pidstat, vmstat, iostat, sar, numactl, taskset, strace, flame graphs, perf, PMU counters, cache misses, branch misses, cycles, instructions, IPC, NUMA, CPU affinity
- Linux: processes, threads, signals, syscalls, virtual memory, file descriptors, sockets, TCP/UDP, epoll, CPU affinity

- C++: RAII, move semantics, templates, atomics, memory ordering, lock-free programming, object lifetime, allocators, alignment, cache lines

- Computer Architecture: CPU pipeline, branch prediction, L1/L2/L3 cache, TLB, RAM, NUMA, SIMD, memory barriers, cache coherence

- Networking: Ethernet, IP, UDP, TCP, multicast, kernel networking, NIC, packet processing, latency, jitter

- HFT Architecture: market data feed, order book, market-data normalization, strategy, signal, risk checks, order management, exchange gateway, order entry, execution
