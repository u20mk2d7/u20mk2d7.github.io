1. Hardware & Memory-Level Architectures (Nanosecond Level)

At the sub-microsecond level, execution time is bottlenecked by CPU cache lines and PCIe bus transfers.

    DOD (Data-Oriented Design): Layouts data strictly for CPU L1/L2 cache locality. Uses Structure of Arrays (SoA) instead of Array of Structures (AoS) to ensure contiguous memory reads and pre-fetching.

    Zero-Copy Architecture: Network packets are processed directly from NIC buffers to application memory without OS kernel intervention or buffer cloning (mmap, DMA).

    Kernel Bypass: Skips the OS TCP/IP stack entirely using specialized libraries (e.g., Solarflare OpenOnload, DPDK) to process network packets directly in user space.

    Lock-Free / Wait-Free Architecture: Eliminates mutexes and condition variables using atomic operations (std::atomic), ring buffers (SPSC/MPMC queues), and memory barriers to prevent thread blocking.

    Mechanical Sympathy Design: Writing code specifically optimized for CPU architecture—aligning variables to 64-byte cache lines to prevent false sharing, avoiding branch mispredictions, and removing runtime allocations (malloc/new).
